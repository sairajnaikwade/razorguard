# RazorGuard — System Architecture

## Overview

RazorGuard is a payment fraud detection platform built for the Razorpay AI Buildathon (Track 02: AI Risk Manager). It provides real-time fraud risk scoring for payment transactions using machine learning, with a full-stack web dashboard for analysts and administrators.

## High-Level Architecture

```
┌─────────────┐     ┌─────────────────┐     ┌──────────────┐
│   Frontend   │────▶│   Backend API   │────▶│  PostgreSQL  │
│  React/Vite  │     │    FastAPI      │     │              │
└─────────────┘     └────────┬────────┘     └──────────────┘
                             │
                    ┌────────▼────────┐     ┌──────────────┐
                    │   ML Pipeline   │     │    Redis     │
                    │  scikit-learn   │     │   (cache)    │
                    └─────────────────┘     └──────────────┘
```

## Components

### Backend (`backend/`)
- **Framework**: FastAPI (async)
- **Database**: PostgreSQL via SQLAlchemy (asyncpg driver)
- **Authentication**: JWT (HS256) with Argon2 password hashing
- **RBAC**: Three roles — ADMIN, ANALYST, VIEWER
- **Migrations**: Alembic
- **Health**: `/api/system/health` checks DB and Redis connectivity

### Frontend (`frontend/`)
- **Framework**: React 19 + TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS v4
- **State Management**: Zustand
- **HTTP Client**: Axios
- **Charts**: Recharts

### ML Pipeline (`ml/`)
- **Training**: `train.py` — full pipeline from data loading to artifact saving
- **Models**: Logistic Regression, Random Forest, Isolation Forest
- **Features**: `features.py` — time-safe feature engineering with leakage prevention
- **Evaluation**: `evaluate.py` — reproduces held-out test metrics from saved artifacts
- **Prediction**: `predict.py` — single-transaction inference using saved artifacts
- **Threshold**: `threshold.py` — business cost-based threshold optimization
- **Metrics**: `metrics.py` — standard binary classification metrics

### Data (`data/`)
- Synthetic transaction dataset generated by `scripts/generate_demo_data.py`
- ~20,000 transactions with ~3% fraud rate

### Docker (`docker/`)
- `docker-compose.yml` orchestrates PostgreSQL, Redis, Backend, and Frontend
- Individual Dockerfiles for backend and frontend services

## Data Flow

1. Transactions enter the system via API
2. Feature engineering extracts behavioral, velocity, and contextual signals
3. ML model scores each transaction with a fraud probability
4. Business threshold determines risk level (LOW / MEDIUM / HIGH / CRITICAL)
5. Results are stored and presented via the dashboard

## Security

- JWT tokens with configurable expiry
- Argon2 password hashing (via pwdlib)
- Role-based access control on all protected endpoints
- CORS configuration for frontend-backend communication
- Environment-based secret management (never hardcoded in production)
